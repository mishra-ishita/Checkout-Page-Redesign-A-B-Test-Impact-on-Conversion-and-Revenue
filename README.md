## Checkout-Page-Redesign-A-B-Test-Impact-on-Conversion-and-Revenue

## Overview
This project evaluates a checkout page redesign by comparing two versions of the experience. The aim is to understand if the new design improves how users complete purchases and how much they spend.

## Background
I wanted to understand why users drop off during checkout, as this directly impacts conversion and revenue. This project explores whether a design change can reduce that drop or unintentionally add friction.

## Problem Statement
Does the new checkout design help increase conversions and revenue, or does it create friction for users?

## Approach
Users were split into two groups and shown either Version A or Version B. Their journey from viewing a product to completing a purchase was tracked and compared across key metrics.

## Key Findings
- Around 19% of users dropped between cart and checkout, showing a clear issue at this step.
- Version A performed better than Version B (62.79% vs 60.56%), meaning fewer users completed purchases in Version B.
- Revenue per user increased slightly from ₹903 to ₹919, showing higher spending despite lower conversion.
- On mobile, conversion dropped more in Version B (64.11%to 61.10%), indicating a possible mobile experience issue.
- Users also took longer to convert in Version B (about 64 hours vs 66 hours), suggesting added friction.

## What this means
The new design does not clearly improve performance. It reduces conversions and slows users down, even though it slightly increases how much users spend.

## Recommendations
- Improve the checkout experience, especially the cart to checkout step.  
- Focus on fixing mobile usability issues.  
- Run another test after addressing these friction points.

## Conclusion
The new checkout design does not perform better overall. It introduces friction and needs further improvement before rollout.
